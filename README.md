# Machine Learning & AI Practice Projects

This repository contains a collection of implementation notebooks and resources covering fundamental machine learning algorithms, deep learning applications, computer vision, and data analysis techniques.

---

## 🛠️ Tech Stack & Tools

* **Language:** Python
* **Environment:** Google Colab / Jupyter Notebook
* **Key Libraries:** OpenCV, YOLOv11, PyTorch/TensorFlow, Scikit-Learn, Pandas, NumPy, Matplotlib

---

## 📂 Repository Structure & Overview

### 👁️ Computer Vision & Deep Learning
* **`AI_Powered_Pedestrian_Detection_and_Multi_Object_Tracking_Using_YOLO11.ipynb`**
  Pedestrian detection and multi-object tracking implementation using YOLOv11.
* **`ANN-Optical_Character_Recognition_7.ipynb`**
  Optical Character Recognition (OCR) pipeline built using an Artificial Neural Network (ANN).

### 📊 Supervised & Unsupervised Machine Learning
* **`DecisionTree.ipynb`**
  Classification and decision boundary visualization using Decision Tree algorithms.
* **`Simple_SVM.ipynb`**
  Binary classification implementation using Support Vector Machines (SVM).
* **`House_price_pred_boston.ipynb`**
  Predictive regression model for house price forecasting using the Boston Housing dataset.
* **`K_MeansClustering_Final.ipynb`**
  Unsupervised customer/data segmentation using the K-Means clustering algorithm.
* **`PCA_2026.ipynb`**
  Dimensionality reduction and feature extraction using Principal Component Analysis (PCA).

### 🛒 Data Mining & Analytics
* **`Market Basket Analysis_Apriori.ipynb`**
  Association rule learning and market basket analysis using the Apriori algorithm.
* **`L2_research_write_article_.ipynb`**
  Data-driven research workflow and automated article summary/generation notebook.

### 📚 Learning Resources
* **`AWT LAB MANUAL NEW.pdf`**
  Supplementary reference and lab manual guidelines.
